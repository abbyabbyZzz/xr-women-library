打开网站的方法

1. 双击本文件夹内的「启动网站.cmd」。
2. 浏览器会自动打开本地网站。
3. 使用网站时，请保持启动后的命令窗口打开。
4. 用完后关闭命令窗口，即可停止本地网站。

请不要直接双击 index.html，也不要直接打开 dist/index.html。
本项目使用 React、TypeScript 和 Vite，需要通过本地 HTTP 服务器加载。

也可以在本文件夹打开终端，运行：
  npm run dev
然后打开终端中显示的 Local 地址，通常为：
  http://127.0.0.1:5173/

项目依赖已经随文件夹复制到这台电脑。如果启动提示缺少依赖，先运行 npm install。
