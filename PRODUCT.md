# XR Women Research Library

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Visitors, students, and researchers discovering academic work about XR, museums, gender, identity, safety, and inclusion. Their tasks are searching, evaluating a paper, opening its publication, and exploring related research or verified virtual-library guidance.

## Product Purpose

A searchable research catalogue and a companion to the XR Women FrameVR research library. The current published implementation reads live metadata from the VR Library Museum Zotero group through the existing catalogue API.

## Operating Context

React, Vite, TypeScript, React Router, and Lucide. Home, catalogue, paper detail, and an internal About project route. The existing public Sites project and the user's local Windows project are maintained together.

## Capabilities and Constraints

Preserve live Zotero loading, retry and error states, search, collection filters, publication-year sorting, URL state, return navigation, publication links, and related-paper network/list views. Preserve original paper metadata and abstracts. Do not invent scholarly connections or FrameVR destinations. The legacy six-paper JSON remains a reference fixture, not a substitute for live data.

- Let exploration reveal real catalogue content.
